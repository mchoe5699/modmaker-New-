# QWERTY's HomeNet (Forge 1.20.1)

한국 아파트식 **홈네트워크** 모드 — 월패드, 공동현관 로비폰 / 세대현관 도어폰, 그리고 월패드로 켜고 끄는 제어 블록.

- Minecraft 1.20.1 / Forge 47.x (47.3.0 기준)
- mod id: `qwertys_homenet`

## 빌드

JDK 17이 필요합니다.

```bash
./gradlew build          # Windows: gradlew.bat build
```

결과물: `build/libs/qwertys_homenet-1.0.0.jar` → `mods` 폴더에 넣기.
개발용 클라이언트 실행: `./gradlew runClient`

## 블록 / 아이템

| 이름 | 설명 |
|---|---|
| **월패드** | 세대 안쪽 벽에 다는 단말기. 우클릭하면 화면이 열림 |
| **공동현관 로비폰** | 실제 아파트 공동현관기(248×279×50.2mm) 비율 그대로 블록 1칸 안에 만든 로비폰. 아래 설명 참고 |
| **세대현관 인터폰** | 링커로 월패드에 연결하면 그 세대의 **세대현관 도어폰** (연결하지 않으면 간이 로비폰) |
| **홈 제어 블록** | 월패드에서 켜면 레드스톤 신호 15 출력 (조명, 피스톤, 문, 가스밸브 연출 등) |
| **스마트 조명** | 월패드에서 켜면 밝기 15로 빛나는 조명 블록 |
| **홈 링커** | 월패드와 기기를 연결하는 도구 |

## 사용법

1. **월패드 설치 → 설정 탭에서 세대 번호 입력** (예: `101-1203`). `101-1203`, `101동 1203호`, `1011203`은 같은 번호로 취급됩니다.
2. **홈 링커로 월패드 우클릭**(선택) → **제어 블록 / 스마트 조명 우클릭**하면 연결. 한 번 더 누르면 해제. (최대 32개, 64블록 이내)
3. 제어 블록을 **맨손 우클릭**하면 이름과 종류(조명·콘센트·난방·환기·가스밸브·도어락·전동커튼·기타)를 정할 수 있습니다. 종류는 월패드에 "켜짐/꺼짐" 또는 "열림/닫힘"으로 표시되고, **일괄소등**은 '조명' 종류만 끕니다.
4. **로비폰**: 공동현관에 인터폰을 달고, 옆에 철문(또는 피스톤 문)을 붙여 둡니다. 방문자가 키패드로 세대 번호를 누르고 **호출**.
5. **세대현관 도어폰**: 홈 링커로 월패드 선택 후 인터폰을 우클릭하면 그 세대 전용 도어폰이 됩니다. 버튼 한 번으로 호출.
6. 월패드가 **딩동** 울리면 (30초) 화면에서 **응답 / 문열기 / 거절**.
   - 응답하면 서로 **메시지**를 주고받을 수 있습니다 (양쪽 근처 8블록 플레이어 채팅에도 표시).
   - **문열기**를 누르면 인터폰이 3초간 레드스톤 신호를 내서 옆의 문이 열립니다.
   - 받지 못한 호출은 **부재중 호출**에 기록됩니다.

## 공동현관 로비폰

실제 공동현관기(248×279×50.2mm) 비율로 **세로 2/3칸 × 두께 0.1칸** 크기, 블록 면 가운데에 붙습니다. 블록을 우클릭하면 기기 화면이 열리고, LCD 키패드·오른쪽 터치키(보안·호출·경비·취소)·카드 인식부를 마우스로 누릅니다(키보드 숫자키도 됨). 블록 정면에도 시계·입력 번호·호출 상태·문열림 아이콘이 표시됩니다.

- **세대 호출**: 세대 번호 → `호출` (로비번호의 동이 앞에 붙음. 주차관제로비=1이면 동 → `동` → 호 → `호출`)
- **경비 호출**: `경비` (경비번호 월패드, 비우면 세대 번호가 `경비실`인 월패드)
- **세대 비밀번호**: 세대 번호 → `비밀번호 입력` → 4자리 → `확인` (월패드 설정 탭에서 지정)
- **공동 비밀번호**: 대기화면 `공동비밀번호 입력` → 4자리 → `확인`
- 비밀번호가 틀리면 **비밀번호 입력 화면이 다시** 뜨고, 3회 틀리면 경비실 자동 호출
- 문이 열리면 **네트워크 아이콘 옆에 문열림 아이콘**이 문열림 시간 동안 표시되고 같은 시간 레드스톤 신호
- `보안`: 키패드 임의 배열 / 대기화면 `취소`: 숫자 크기(작은→보통→큰, 항상 버튼 안) / `도움말`
- 근접센서: 플레이어가 다가오면 화면이 켜짐 (근접센서 데이타 40 ≈ 2칸)

### 출입 카드

`출입 카드`(종이 2 + 철 조각 + 레드스톤)를 들고 로비폰을 우클릭하면 카드를 댄 것으로 인식합니다. 카드마다 고유 번호가 있습니다.

- 세대 카드 → 문열림 / 마스터 카드 → RF 카드 메뉴 바로 진입 / 등록용 카드 → 세대 카드 등록 화면
- 화면이 열려 있을 때는 카드를 손에 들고 **카드 인식부(CARD)** 를 눌러도 됩니다.

### 관리자 모드

대기화면에서 **`호출` 다음 `경비`** → 관리자 비밀번호(초기값 **`0000`**).

- `1`~`7` 항목, `←` `→` 페이지(6페이지), `0` RF 카드 설정, `9` 근접센서 설정, `취소` 나가기
- 편집 중 `호출` = 지우기, `경비` = 저장. 로비번호는 숫자 → 하단 `동` / 숫자 → 하단 `라인`
- **RF 카드 설정**: 1 마스터 카드 등록, 2 RF 등록용 카드 등록 (카드 접촉 → `0`), 3 세대용 RF 카드 등록 및 삭제
  (1 세대 카드 등록: 동 → `*`, 호 → `#`, 카드 접촉 / 2 카드 삭제: 카드 접촉 / 3 세대 카드 삭제: 동·호 입력 후 `#` 한 번 더 / 4 카드 전체 삭제: `0`)
- `호출`·`경비`를 누르면 상위 메뉴로

동작하는 설정: 로비번호, 경비번호, 시스템 비밀번호, 주차관제로비, 경비 문열림 비밀번호, 공동 비밀번호(+사용여부), 근접센서, 키 LED, LCD 백라이트, 숫자 음, 문열림 시간, 멜로디·키톤 볼륨. 네트워크·DSP 항목은 실제 기기처럼 값만 표시됩니다.

### 글꼴

LCD 글꼴(`assets/qwertys_homenet/font/lcd.ttf`)은 사용자가 제공한 파일이며 라이선스상 재배포가 금지되어 있어 **저장소에는 올리지 않습니다**. 빌드한 jar에만 넣어서 개인적으로 사용하세요. 직접 빌드할 때는 같은 경로에 글꼴 파일을 넣으면 됩니다. 텍스처는 `python3 tools/gen_lobby_phone.py`로 다시 만들 수 있습니다(글꼴 필요).

## 구조

```
src/main/java/com/qwerty/homenet/
├─ HomeNet.java                  메인 클래스
├─ registry/                     블록·아이템·블록엔티티·크리에이티브 탭 등록
├─ block/                        월패드, 인터폰, 제어 블록, 스마트 조명, 기기 종류
├─ blockentity/                  각 블록의 상태와 통화 로직
├─ intercom/                     통화 상태, 인터폰 상태, 메시지, 부재중 기록
├─ data/UnitRegistry.java        세대 번호 → 월패드 위치 (월드 저장 데이터)
├─ item/HomeLinkerItem.java      홈 링커
├─ network/                      패킷 (서버↔클라이언트)
└─ client/                       월패드 / 인터폰 / 기기 설정 화면
```

화면은 텍스처 없이 코드로 그립니다 (`client/HomeNetScreen.java`의 색상 상수로 테마 변경 가능).
벨소리는 바닐라 소리 블록 차임을 높낮이 두 번 울려 "딩-동"을 냅니다.
